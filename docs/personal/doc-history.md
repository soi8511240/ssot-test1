# 문서 발전 기록 (`docs/personal/doc-history.md`)

> 이 프로젝트의 SSOT 문서가 **어디서 출발해 어떻게 바뀌었는지** 남기는 기록입니다. 사람이 읽는 용도이며(발표·회고), AI 작업 규칙은 `AGENTS.md`가 기준입니다.
> 문서를 바꿀 때마다 3장에 한 줄씩 추가합니다. 형식: **어떤 문제가 있었나 → 무엇을 바꿨나 → 어느 문서에 반영했나**

---

## 1. 출발점

- 처음 받은 `.txt` 문서 8개(`AGENTS`, `CLAUDE`, `requirements`, `design`, `tasks`, `ia-spec`, `guide-spec`, 스택 파일).
- 일반 CSS 3파일, npm, IA·Guide 화면 직접 구현을 전제로 한 범용 규칙이었습니다.
- 프로젝트 정보와 디자인 원본은 빈칸이었습니다.

이 프로젝트는 여기서 출발해 **템플릿(publishTemplate)을 기준으로 문서를 맞추는** 방향을 택했습니다.

## 5. 남은 과제 (우선순위 순)

1. 자주 쓸 컴포넌트 문서 추가: Select, Radio, Modal(Dialog), Table, Tabs, Pagination
2. 리허설 1회차 → 문서 보완 → 2회차
3. 백로그 17건 중 페이지에 바로 영향을 주는 것 수정 (Icon 색, Accordion 스타일, DatePicker 접근성)
4. 규칙 검사 스크립트 (hex 색, 목록 등록 누락 등)
5. 배치 규칙 보완 (제목 단계, 카드 중첩)
