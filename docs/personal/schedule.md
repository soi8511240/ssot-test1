| 기준 | 질문 | 현재 상태 |
| --- | --- | --- |
| 문서끼리 맞나 | 서로 다른 말, 같은 내용 중복, 끊긴 참조가 없나 | 점검 안 함 |
| 읽는 길이 분명한가 | AI가 작업마다 어떤 문서를 읽을지 정해져 있나 | 읽기 순서만 있음 |
| 규칙을 기계로 확인하나 | 규칙 위반을 검사로 잡나 | 린트·빌드만 |
| 다른 프로젝트에 재사용되나 | `requirements.md` 0장만 바꾸면 새 프로젝트에 쓸 수 있나 | 점검 필요 |
| 사람이 시작하기 쉬운가 | 처음 받은 사람이 무엇부터 할지 알 수 있나 | README 점검 필요 |
| 실제로 작동하나 | 새 대화에서 셋팅대로 움직이나 | 리허설 안 함 |
