# 업무 준비 체크리스트 (`docs/personal/work-checklist.md`)

> 퍼블 PL로 실제 프로젝트에 들어갈 때 확인하고 협의할 것을 **직접 채워 쓰는 양식**입니다.
> 사람이 쓰는 용도이며 AI 작업 규칙(SSOT)이 아닙니다. 확인하면 `[x]`로 바꾸고 `답:` 뒤에 적습니다.

- [ ] 컴포넌트 세트 전체를 넘긴다

    - [ ] 모든 크기
